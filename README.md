# CLOACHY v1.0.0 (Release)

**BY @Zdevlops**

Aplikasi Android pendamping Roblox bernuansa **Oceanic Blue Glassmorphism** dengan fitur:
- **Launch Roblox & Auto-Inject FFlag** (Hybrid Shizuku Direct + Built-in APK Patcher)
- **Background GPU Auto-Guard** (>80% otomatis turun ke Lv. 10 & 100% otomatis turun ke Lv. 1)
- **Visual & Strict App Lock** (Grafik Lv. 1–21, Lighting, Texture, Shadow)
- **In-App Auto-Update** di tab **Profil** dengan notifikasi rilis GitHub otomatis

## Build APK Otomatis (GitHub Actions)
1. Push seluruh isi proyek ini ke repositori GitHub (`Zdevlops/CLOACHY`).
2. Workflow `.github/workflows/build.yml` otomatis mengompilasi `Cloachy-v1.0.0-release.apk` dan `Cloachy-v1.0.0-debug.apk` di tab **Actions -> Artifacts**.
3. Workflow `.github/workflows/rapikan.yml` menjaga struktur dan kebersihan file repositori secara otomatis.
